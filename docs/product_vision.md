# Visión de producto

**My Works App** conecta hogares de Puerto Montt con profesionales de oficio y deja el pago retenido hasta que el cliente recibe conforme el trabajo.

## Para quién

- El cliente compara precio, nota y cercanía, agenda una hora publicada y paga con Transbank sin entregar la tarjeta a la app.
- El profesional publica tarifas, horario y zona, acepta el pedido, parte con un PIN y cierra con evidencia fotográfica.
- Administración verifica profesionales y media disputas desde la consola de escritorio.

## Problema

La contratación a domicilio suele ser informal: el cliente no sabe a quién elegir, el profesional no tiene un canal estable y el pago queda expuesto si el trabajo no se termina.

## Promesa

Un mismo flujo en app, web y consola: buscar en Puerto Montt, agendar, retener el pago, subir evidencia, recibir conforme y calificar. La comisión del servicio (5 %, mínimo $1.000) se descuenta del profesional. El cliente paga la tarifa más el traslado, en pesos enteros.

## Fuera de esta entrega

MFA obligatorio para todos los usuarios, payout bancario automático y Transbank en producción. La consola de escritorio sí pide un segundo factor TOTP.

La web está publicada en https://myworksapp.cl.
